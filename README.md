# New York Mets Exploratory Data Analysis & Statistical Modeling

Exploratory data analysis and statistical modeling on 60+ years of New York Mets batting data using Python, pandas, seaborn, matplotlib, numpy, and scipy.stats.

## Key Project Highlights

* **Data Wrangling & Cleaning:** Cleaned and analyzed 60+ years of New York Mets offensive metrics (~2,700+ records) using `pandas` and `numpy`, filtering out low-sample noise (min 250 AB) to evaluate core performance drivers.
* **Statistical Modeling & Hypothesis Testing:** Conducted probability analysis, one-sample t-tests, and Z-score normal distribution modeling using `scipy.stats` to quantify high-impact offensive seasons (OPS > 0.850).
* **Data Visualization:** Designed exploratory visualizations using `seaborn` and `matplotlib` to present player rankings, stat distributions, and feature correlation heatmaps.
